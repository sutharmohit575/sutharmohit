## ✨ Features

- **Brutalist Design** — Bold black/red aesthetic with dot-grid background and stark typography
- **Fully Responsive** — Works on all screen sizes
- **Smooth Animations** — Scroll-reveal effects and cursor tracking
- **Developer Journey Timeline** — From first HTML file to full-stack projects
- **Skills Section** — Visual progress bars with animated tech strip
- **Projects Showcase** — Featured project grid with stack tags
- **Working Contact Form** — Powered by [Formspree](https://formspree.io), messages go straight to Gmail
- **Zero Dependencies** — Pure HTML, CSS, and vanilla JavaScript

## 📬 Contact Form Setup

The contact form uses **Formspree** — no backend needed.

The form endpoint is already connected to `sutharmohit575@gmail.com`.  
Every message submitted on the site lands directly in the inbox.

To use your own email:
1. Go to [formspree.io](https://formspree.io) and create a free account
2. Create a new form and copy your endpoint URL
3. In `index.html`, find the `<form>` tag and replace the `action` value:

```html
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
```

## 🌐 Deploy on Vercel

```bash

git add .

# 3. Click Deploy — done!
```

Vercel auto-detects static HTML. No configuration needed.
