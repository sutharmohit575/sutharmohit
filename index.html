// ABOUT ME

THE
STORY

It started with a single HTML file — a blank page, a blinking cursor, and a question: "What can I make with this?" That curiosity never left.

I'm Mohit Suthar, a self-driven developer from India who went from copying tutorials to shipping full projects. Every bug I fixed, every concept I broke and rebuilt — each one made me a sharper thinker and a better builder.

My journey has taken me from pure HTML/CSS → JavaScript → React → Node.js → databases and beyond. I don't just build things that work; I build things that feel right.

When I'm not coding, I'm studying how great products are designed, obsessing over UI details, or finding new tools to add to my arsenal.
