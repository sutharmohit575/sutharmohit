// ABOUT ME

THE
STORY

It started with a single HTML file — a blank page, a blinking cursor, and a question: "What can I make with this?" That curiosity never left.

I'm Mohit Suthar, a self-driven developer from Ahmedabad, Gujarat. I went from writing my first div to building AI-powered web apps with Python, Django, and FastAPI — deployed live and used by real people.

My biggest project is MOHIT.EXE — a terminal-style portfolio OS with RPG skill trees, boss fights, Snake.EXE, an AI chatbot powered by DSA algorithms (Trie, LRU Cache, Min-Heap, BFS), and 26 unit tests. That's the kind of developer I am.

I also built JobAI — an AI-powered job portal with Django, PostgreSQL, resume upload, user auth, and deployed on Vercel. Every project teaches me something new, and I keep going.
